# 게시글 작성기

2026-10-06 기준. Web 이슈 #25와 API 이슈 #76의 현재 계약이다. 과거 작성기 이력은 Git history에서 확인한다.

## 화면

- `/posts/new`, `/posts/{id}/edit`는 흰색 작성 전용 화면이다. 일반 사이트 메뉴 대신 얇은 고정 도구막대와 작성자 표시를 사용한다.
- 제목과 본문은 테두리 없는 작성 공간이다. 하단에 나가기·임시저장·완료를 고정한다. 일반/HTML/마크다운 형식을 선택한다.
- 일반 편집 도구: 이미지, 서체·크기, 굵게·기울임·밑줄·취소선, 글자색·배경색, 정렬·제목, 인용·목록·표·링크·구분선. 추가 삽입 메뉴에 목차·지도·HTML·코드·테이블 명세·아키텍처·특수문자·접는 글을 제공한다.
- HTML/마크다운은 원문과 안전한 미리보기를 표시한다. 형식 변환 전 확인하며 HTML→마크다운은 원문 HTML을 보존한다. 시각 편집기는 지원하는 문단/표/이미지/구조로 정규화하므로 원문 전환 안내를 따른다.
- 기존 TEXT는 문자 그대로 표시하고 시각 편집 시 HTML로 바꾼다. CODE의 언어 HTML은 계속 코드이며 실행하지 않는다. 기존 TABLE/ARCHITECTURE와 순서는 유지한다.

## 저장과 발행

- 신규 임시저장은 서버 HIDDEN + `draft:true`다. 빈 제목은 서버에만 `임시 글`로 대체하며 입력란은 그대로 둔다. 무효 구조는 저장할 수 없다. 자동 저장은 제공하지 않는다.
- 완료는 발행 팝업을 연다. 공개/비공개·주제·게시판·숫자 주소/직접 입력 주소를 선택하고 취소/발행한다. 요약·프로젝트·기술 태그는 접힌 추가 설정에 둔다.
- 숫자 주소는 블로그 글 번호다. 직접 주소는 영문 소문자·숫자·하이픈으로 최대 200자, 숫자만 또는 search는 거부한다. 중복 주소의 서버 접미사 처리 결과를 사용한다.
- 임시 글의 최초 발행은 `draft:false`와 공개 상태·본문·slug를 함께 PATCH한다. 이미 발행을 완료한 글은 비공개여도 주소 변경/임시 글 복귀를 허용하지 않는다.
- 발행된 글의 임시저장은 현재 브라우저 localStorage에 보관해 서버의 공개 내용을 바꾸지 않는다. 회원+글 ID로 분리하며 재접속 시 복원을 확인한다. 비밀 토큰·서명 이미지 URL은 저장하지 않는다. 발행 성공 후 로컬 편집본을 삭제한다.
- 새로고침/닫기와 나가기에서 미저장 변경을 안내한다. 일반 사이트 내부 링크 전체에 이동 방지 기능을 추가하지 않는다. 쓰기 오류를 자동 재전송하지 않으며 입력을 유지한다.

## 본문 이미지와 보안

- 이미지 첨부는 USER 소유자 API `/posts/{id}/images`를 사용한다. 새 글에서는 비공개 임시 글을 먼저 만든다. JPEG/PNG/WebP, 10MiB, 실제 디코딩/크기 제한·WebP 변환과 글당 50개 제한은 서버가 검증한다.
- 편집 중 서명 URL을 미리보기에만 사용하고 본문에는 `/api/v1/posts/{id}/images/{imageId}/content`의 고정 HTTPS 주소를 저장한다. 재편집 시 소유자 목록에서 새 서명 URL을 받는다.
- 공개 이미지 주소는 실제 공개 본문에서 참조하는 파일만 302 연결한다. 미참조·초안·숨김·차단·삭제 글은 404다. 이미 발급된 서명 URL은 만료까지 유효할 수 있다.
- 사진을 본문에서 제거하면 공개 참조도 사라진다. 업로드 원본의 즉시 삭제 UI는 이번 범위에 없으며 글 삭제 시 삭제 큐가 파일을 회수한다. 반복 업로드는 50개 제한에 포함된다.
- HTML/마크다운 출력은 공통 허용 목록으로 sanitize-html 처리 후 렌더링한다. script, 이벤트, 위험한 URI·CSS·임의 iframe과 앱의 CSS 클래스를 끌어오는 마크업은 제거한다. 원문은 서버에서 데이터로 보관하며 모든 렌더러에 동일 정책이 필요하다.
- 지도는 좌표로 생성한 HTTPS OpenStreetMap export/embed.html만 허용한다. 임의 지도 HTML/스크립트는 허용하지 않는다. 고정 sandbox/referrer 정책을 적용한다.
- 인증은 기존 메모리 Access Token, 보호된 Refresh Cookie, 소유권·상태 검사 그대로다. 운영 비밀 파일은 빌드에 복사하지 않는다.

## 2026-10-08 본문 블록과 서식 도구

일반 모드는 한 TipTap 문서에서 문단, 일반 표, 코드, 테이블 명세, 아키텍처를 편집한다. 코드는 블록 왼쪽 위 언어 선택을 사용하고 명세는 고정 컬럼 양식을 유지한다. 아키텍처 편집은 대화상자의 적용 시에만 본문에 반영한다. 저장 시 기존 HTML/CODE/TABLE/ARCHITECTURE API 블록으로 순서대로 분할하므로 별도 본문 계약 변경은 없다.

제목은 1~3 단계이며 본문과 서로 다른 크기 목록을 제공한다. 제목 끝에서 Enter를 누르면 본문 16px로 전환한다. 글자색·배경색은 고정 팔레트로 선택한다. 표 삽입은 8행×10열 격자 선택이며 생성한 표의 오른쪽과 아래 버튼으로 마지막 행·열을 추가·삭제한다. 목차는 읽기 전용으로 실제 제목을 따라 자동 갱신한다. 본문/바깥 클릭과 Escape는 열린 삽입·색상 팝업을 닫는다.

태그는 기존 목록 선택과 `#springboot #아무개` 자유 입력을 함께 제공한다. 신규 태그는 인증된 프로필 완료 회원이 `POST /api/v1/tags`로 등록하고 반환된 ID를 기존 tagIds에 연결한다. 정규화·길이·사용 문자 검증은 서버에서 다시 수행한다.

개발용 `/dev/writer`는 서버 데이터 없이 저장·재편집을 검증하며 운영 빌드에서는 404로 차단한다.

## 작성 도구 상호작용 (2026-10-08, #31)

- 도구 그룹은 작성 화면 중앙에 배치한다. 문단 정렬은 SVG 버튼을 눌러 왼쪽 → 가운데 → 오른쪽 → 양쪽 순으로 변경한다. 글머리 목록과 번호 목록을 각각 제공한다.
- 표 오른쪽·하단의 얇은 컨트롤은 hover/focus에서 표시하며 마지막 열·행을 추가하거나 삭제한다. 왼쪽 위 X는 표 전체를 삭제한다. 터치 화면에서는 컨트롤을 표시한다.
- 코드 본문은 줄을 임의로 접지 않고 가로 스크롤한다. 기존 코드 안에 붙여넣으면 현재 언어와 블록을 유지하며 평문으로 삽입한다. 복사는 저장 대상 원문 전체를 사용한다.
- 접는 글은 별도 제목 입력과 펼침 버튼을 제공하며 제목·본문·열림 상태를 저장한다.
- 마크다운 제목은 표준대로 `### 제목`처럼 공백이 필요하다. 한 번의 Enter는 표시상 줄바꿈, 빈 줄은 문단 분리다. 일반 → 마크다운 전환 시 보존 HTML 뒤에 빈 줄을 두어 이어 쓰는 마크다운을 구분한다.

검증: 개발 전용 작성기에서 Java 다중 행·긴 줄 붙여넣기, 복사 원문 일치, 저장 후 재편집 원문·언어 유지, 가로 스크롤을 확인했다. 정렬 4단계 순환, 번호 목록, 표 2×3 → 3×4 → 2×3 증감과 전체 삭제, 접는 글 제목 변경·접기/펼치기·저장 복원, 마크다운 제목/한 줄바꿈/번호 목록을 확인했다. 운영 사용자 데이터는 변경하지 않았다.

## 2026-10-08 · 작성·조회 조작 정리 (#33)

표/삽입 메뉴는 클릭한 도구 바로 아래에 표시한다(화면 끝에서는 가로 위치를 제한). 표 팝업에서 포인터가 벗어나면 선택을 취소한다. 목록 도구는 한 버튼에서 없음 → 동그라미 → 번호 → 없음으로 전환한다. HTML/마크다운은 최대 1400px 원문/미리보기 공간을 사용하며 좁은 화면에서는 세로로 배치한다. 일반 표 편집과 발행 화면의 너비·테두리·셀 여백을 맞춘다.

태그는 본문 아래에서 #이름을 입력하고 Enter/쉼표로 추가한다. 기존 태그 전체 목록이나 검색 선택창은 표시하지 않으며 기존 ID 재사용 및 서버 검증은 유지한다. 게시판 미선택은 전체 게시글(기본)로 안내한다. 전체 게시글 탭은 다른 게시판 글도 포함하며 삭제 대상이 아니다. API boardId=null 계약은 유지한다.

게시글은 따봉 SVG 좋아요와 개수만 표시하고 평상시 좋아요/댓글 새로고침을 제거한다. 실패 시 재조회는 유지하며 변경 후 자동으로 데이터를 조회한다. 비밀 댓글 체크는 입력 위, 등록 버튼은 오른쪽에 둔다. 등록 성공 문구는 생략하고 오류는 유지한다. 로그인된 작성자에게 게시글 수정 링크를 제공하며 서버 소유권 검증은 바꾸지 않는다.

## 작성기 입력·블록 이동 (Web #49 / API #92)

제목 끝에서 Enter를 누르면 기존 자동 빈 문단을 재사용하거나 본문 문단 하나만 생성한다. 새 문단의 서식은 본문으로 전환된다. 목록 가운데/오른쪽 정렬은 기호와 첫 문단이 함께 이동하며 공개 본문에서도 같은 정렬을 적용한다.

일반 편집에서는 본문 블록 근처에 커서를 놓으면 왼쪽 이동 손잡이가 나타난다. 손잡이를 드래그해 표시되는 삽입선에 놓으면 제목·문단·목록·이미지·표·코드·명세·아키텍처를 포함한 최상위 블록 전체를 이동한다. 목록/토글 내부 항목은 부모 블록과 함께 이동한다. 이동 도중 문서가 변경되면 이동을 취소하고 기존 문서를 보존한다. Alt+↑/↓ 이동과 Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z 이력을 제공하며 삽입 메뉴에는 되돌리기/다시 실행을 표시하지 않는다.

테이블 명세의 텍스트 입력은 IME 조합 중인 값을 로컬에 유지하고 조합 종료 또는 포커스 이탈 때 문서에 반영한다. 요약 입력칸은 제거했다. 저장할 때 본문 텍스트/HTML/Markdown의 읽을 수 있는 내용에서 최대 200 Unicode 코드 포인트를 summary로 저장한다. 코드·명세 JSON·목차 중복 문구는 제외한다. 기존 글의 요약은 다음 저장 전까지 유지한다.

본문 이미지 CDN 경로 누락은 API #92에서 수정한다. 로컬 R2 비활성 환경과 운영 CDN은 별개이며, 브라우저에 R2 키나 CDN 서명 키를 전달하지 않는다.
