# 홈·개인 블로그 글 카드

Web #61: 홈 공감받은 글·최신 글과 개인 블로그 글 목록에 작은 우측 썸네일과 고정 행 배치를 적용한다.

- 이미지와 요약이 없어도 메타·제목·요약·태그 행 및 이미지 열을 유지한다. 가짜 이미지나 안내 문구를 채우지 않는다.
- 제목과 요약은 각각 최대 두 줄. 개인 블로그 태그는 한 줄만 표시한다. 전체 콘텐츠는 상세에서 읽는다.
- 홈 공감받은 글은 데스크톱 3열·80×80 썸네일. 중간 화면부터 1열로 전환한다.
- 최신 글과 개인 블로그는 160×106, 모바일은 96×72. 본문 이미지에는 적용하지 않는다.
- 각 목록 내 카드 높이는 이미지·요약·태그 유무에 무관하게 같다. 화면 폭별 카드 높이는 달라질 수 있다.
- API·인증·업로드·대표 선택 계약은 변경하지 않는다.
