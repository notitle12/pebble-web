# 게시판 관리와 직접 입력 태그 (Issue #43)

게시판 관리 `/me/boards`는 삭제 불가 전체 게시글 기본 항목과 3단계 계층 목록을 표시한다. 그룹 접기/펼치기, 새 게시판/하위 추가, 이름·상위 게시판·표시 순서 편집, 자식 없는 게시판 삭제를 제공한다. 목록 선택 후 오른쪽에서 설정하고 모바일에서는 아래 편집 패널로 표시한다. 표시 순서는 작은 수부터이며 같은 순서는 기존 API의 ID 기준이다. 게시글 수는 현재 구조 API에 없어 임의 수치를 표시하지 않는다. 하위 게시판 수만 표시한다. 삭제 확인 시 연결된 글은 전체 게시글에 남는다는 정책을 안내한다. 저장 결과가 불명확할 때는 목록 확인을 먼저 요구하고 자동 재저장하지 않는다. 자신/후손 및 3단계를 초과하는 상위 후보는 선택에서 제외한다. 서버 검증은 최종 기준이다.

게시글과 프로젝트 작성 태그는 같은 직접 입력 컴포넌트를 사용한다. #springboot #아무개 또는 Enter/쉼표로 추가하고 칩의 삭제 버튼으로 제거한다. 사전 전체 태그 목록/체크박스는 불러오거나 표시하지 않는다. 기존 비활성 태그도 연결된 이름과 제거 기능은 유지한다. 계정 변경·언마운트 이후 비동기 태그 응답은 적용하지 않으며 프로젝트 태그 추가 중 다른 필드를 편집해도 최신 필드를 보존한다.

태그 저장은 기존 `tag`, `post_tag`, `project_tag`를 유지한다. `POST /tags`가 이름을 정규화하고 기존 ACTIVE 태그를 재사용하거나 생성하며 게시글·프로젝트 쓰기는 tagIds로 연결한다. 문자열 하나의 칼럼이나 쉼표 문자열로 바꾸면 태그별 검색·중복·이름 일관성·참조 무결성에 불리하다. 자유 입력은 UI 정책이며 별도 DB 변경을 요구하지 않는다. 태그 생성 뒤 콘텐츠 저장 전까지 미연결 태그가 생길 수 있는 기존 계약은 유지한다.
