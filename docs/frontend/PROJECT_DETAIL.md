# 공개 프로젝트 상세 인계

2026-10-03 · Issue #10 · feature/10-public-project-detail · PR #9 기반, dev 통합 전.

프로젝트 목록 제목에서 /projects/{id}로 이동한다. Guest/no-store GET /projects/{id}로 이름·소유자·요약·태그·진행 상태·기간·소개·주요 기능·구조 설명·실행 방법·외부 링크를 표시한다. 제목 metadata와 상세는 요청 안에서 React cache로 조회를 공유한다. API id·날짜·배열·지원 링크 유형을 검증하며 데이터가 없는 선택 영역은 생략한다.

사용자 설명은 일반 텍스트로 표시한다. HTTP(S) 절대 주소이며 자격 정보가 없는 링크만 활성화하고 그 외 링크는 사용할 수 없다는 안내를 표시한다. 새 탭에는 noopener noreferrer와 안내를 제공한다. 주요 기능·링크는 displayOrder로 정렬한다. 날짜만 있는 startedOn/completedOn은 시간대 변환 없이 표시한다.

GET /projects/{id}/posts로 관련 공개 글을 페이지별로 조회한다. URL page만 지원하고 API 필터·페이지 계약을 유지한다. 기존 PostPage 검증과 PostCards를 재사용하고 handle/urlKey로 글 상세에 연결한다. 관련 글 로딩·빈 목록·범위 밖·잘못된 page·조회 실패/재시도를 본문과 분리한다. 프로젝트 404는 미존재 안내, API/네트워크 오류는 재시도 화면이다.

목 데이터에서는 첫 프로젝트에 21개 글을 연결하고 다른 프로젝트는 관련 글 0개다. npm run dev:mock에서 프로젝트 제목을 클릭한다. 댓글·좋아요·편집·미디어 갤러리는 이번 범위 밖이다.

검증: Node 22에서 테스트 18개·빌드·타입 검사 통과. 목 브라우저의 목록→상세, 텍스트/주요 기능/링크 속성, 관련 글 2페이지와 글 상세 연결, 관련 글 없음·미존재, 390px 가로 넘침을 확인했다. 외부 URL 스킴/자격 정보, 날짜/주소/응답 무결성, 503과 404, 관련 글 페이징은 테스트했다. 실제 로컬 백엔드의 미존재 프로젝트와 관련 글 조회는 not-found로 구분했다. 실제 프로젝트가 있는 상세·운영 API·Workers는 미검증이다.
