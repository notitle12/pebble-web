# 게시판 직접 편집 — Web Issue #45

블로그 설정은 사이드바 문서 흐름의 마지막 항목이다. 방문자·링크 구분선을 제거하고 설정 위 하나만 남긴다. 고정 위치와 내부 스크롤을 사용하지 않는다.

게시판 추가는 기본 이름(중복 시 숫자 추가)으로 실제 루트 게시판을 생성하고 맨 위에서 이름 입력에 포커스한다. 취소는 이름 편집을 취소하며 이미 생성된 게시판은 유지한다. 수정은 인라인 이름 편집, 삭제는 기존 하위 게시판 제한과 확인을 유지한다.

손잡이를 드래그하면 대상 행 상/하단은 앞/뒤 삽입이다. 가운데에서 2초 동안 머물면 하위 이동이 강조되고 놓을 때 저장한다. 자기 자신·자손·3단계 초과·같은 부모의 동일 이름은 차단한다. 키보드도 Space, ↑↓, →(2초), Enter, Esc를 지원한다.

기존 POST/PATCH 계약을 사용한다. 순서 정규화는 직렬 PATCH이며 원자적 배치 API는 없다. 중간 실패 시 일부 변경이 남을 수 있으므로 결과를 성공으로 표시하거나 자동 재시도하지 않는다. 쓰기를 잠그고 서버 목록 확인을 제공한다. 계정 변경·언마운트 시 후속 요청과 결과 반영을 중단한다.

검증: Node 22 전체 테스트 146개·타입 검사·격리 Workers 빌드. 합성 API 브라우저에서 생성/이름 저장, 키보드 2초 하위 이동, 마우스로 하위 게시판 루트 이동, 사이드바 static 위치와 방문자/링크 border 0 및 설정 border 1px를 확인했다. 운영 회원 데이터를 변경하는 테스트는 하지 않았다.
