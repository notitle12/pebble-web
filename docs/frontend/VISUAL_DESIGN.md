# 공개 화면 디자인 갱신 (2026-10-04)

사용자가 기존 화면의 디자인 개선을 요청해 홈·프로젝트·개인 블로그·태그·주제·공개 상세의 시각 기준을 갱신했다. 홈은 여러 개발자의 기록을 둘러보는 공간이고, 개인 블로그는 작성자와 글에 집중하는 공간이다.

## 현재 기준

- 배경 `#FAFAF8`, 본문 `#242721`, 보조 글자 `#73776F`, 구분선 `#E2E5DE`, 포인트 `#3657D6`.
- 파란 조약돌 로고를 유지하고 반복되는 흰 패널·푸른 배경을 줄인다. 제목, 여백, 얇은 선으로 콘텐츠 계층을 표현한다.
- 시스템 한글 글꼴을 사용한다. 외부 글꼴·새 UI 라이브러리·외부 이미지 요청을 추가하지 않는다.
- 홈은 큰 소개 제목과 작성자/날짜를 분리한 기록 목록, 프로젝트는 표지와 설명을 분리한 2열 포트폴리오, 개인 블로그는 작성자 정보와 읽기 목록을 배치한다.
- 모바일에서 프로젝트는 1열, 개인 블로그는 작성자 정보 다음에 글 목록, 검색어는 한 줄 전체 폭, 태그와 분류/상태는 나란히 배치한다. 입력 글자는 16px 이상, 주요 탐색·검색 터치 영역은 44px 이상을 사용한다.
- 프로젝트 표지는 장식용 SVG다. 실제 프로젝트 화면이나 서버 구성도라고 주장하지 않는다. 제목·태그·작성자·상태·개수는 API 데이터만 표시한다. 프로필의 원형 도형도 장식이며 업로드 사진이 아니다.
- 표지의 hover 이동은 reduced-motion 환경에서 제거한다. 본문 표·코드·아키텍처 블록의 동작은 기존 렌더러를 사용한다.

## 구현 위치

공통 시각 조정은 `src/app/design.css`, 구조와 기능 기준은 기존 `globals.css`와 각 컴포넌트다. 프로젝트 표지는 `src/features/project/components/project-cover.tsx`다. 배포/인증/API 계약을 변경하지 않았다. 실제 네이버 공급자 로그인 검증은 [홈·블로그·로그인 인계](BLOG_HOME_LOGIN.md)의 별도 항목이다.

## 검증

- 기존 테스트 51개 통과, 최종 Next.js 배포 빌드와 TypeScript 검사 통과.
- 실제 로컬 API의 프로젝트 목록 및 React 검색 결과 1개 확인.
- 데스크톱 홈·프로젝트·개인 블로그 화면 확인. 모바일 홈과 개인 블로그는 실제 콘텐츠 폭 375px에서 가로 넘침 없음, 프로젝트도 모바일 1열 확인.
- 로컬 검증 콘텐츠는 테스트 계정과 테스트 데이터다. 운영 콘텐츠·실제 네이버 인증 성공을 뜻하지 않는다.

이전 [디자인 초안](DESIGN.md)의 푸른 배경 기준은 초기 참고 기록이다. 현재 공개 화면을 수정할 때는 이 문서를 우선 확인한다.
