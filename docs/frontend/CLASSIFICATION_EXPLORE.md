# 공개 태그·분류 탐색 인계

2026-10-03 · Issue #12 · feature/12-classification-explore · PR #11 기반, dev 통합 전.

헤더의 태그(/tags)와 분류(/categories) 메뉴를 추가했다. Guest/no-store GET /tags·/categories를 사용하고 서버 순서대로 표시한다. 태그/상위·하위 분류를 선택하면 해당 tagId/categoryId의 공개 글 목록으로 이동한다. 분류와 개인 Board는 섞지 않고 없는 집계는 표시하지 않는다.

분류 응답은 2단계, parentId 관계, 양의 문자열 ID·중복·상태·children을 검증한다. INACTIVE 항목은 기존 분류/태그로 표시하며 공개 탐색에서는 계속 사용할 수 있다. 신규 글 작성의 분류 선택 규칙은 이번 공개 탐색과 별개다.

글 API와 URL에 categoryId를 추가했다. 검색 q·tagId·categoryId는 AND로 전달하고, 상위 분류는 서버가 하위 글까지 포함한다. 검색 제출은 첫 페이지로, 페이지 이동/재시도는 조건을 보존한다. 프로젝트는 categoryId를 지원하지 않으므로 계속 거부한다. 입력 오류·빈 탐색·조회 실패/재시도·로딩과 개별 태그/분류 조회 실패를 제공한다.

태그 선택의 기존 동작을 components/choice-picker.tsx로 분리해 분류에도 재사용한다. 각 선택기는 독립된 name/id로 submit하며 폭 제한·긴 이름·스크롤·외부 클릭/Escape 닫기·초점 복귀를 유지한다. 모바일 헤더는 메뉴를 별도 줄에 표시한다.

npm run dev:mock으로 태그 10개와 2단계 분류 3그룹(기존 그룹 포함)을 확인한다. 목 검색은 제목·Tag·연결/상위 분류 이름을 검색하며 본문 검색은 목 데이터에 없다. empty/error/slow는 분류와 태그에도 적용한다.

검증: Node 22에서 테스트 21개·빌드·타입 검사 통과. 트리 경계·부모/중복·상태, 상위/하위 동등 필터, 검색/태그/분류 AND, URL 조건 보존, 프로젝트 미지원 필터, 빈/오류는 테스트했다. 브라우저에서 메뉴·태그/상위 분류→글 목록·AND 검색·기존 그룹·390px 가로 넘침 없음을 확인했다. 실제 로컬 API 분류 5개·태그 8개·조합 검색 0개가 조회/검증 함수를 통과했다. 실제 글이 있는 분류 결과·운영 API·Workers는 미검증이다.
