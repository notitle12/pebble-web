# 블로그 생성·프로필 (2026-10-05)

사용자 요청으로 초기 화면 제목을 블로그 생성, 저장 버튼을 저장으로 바꾸었다. 연결된 SNS 기본 닉네임을 표시하고 최초 중복 확인·숫자 후보 재확인과 수동 중복 확인을 제공한다. 블로그명 100자·닉네임 30자(정규화 후 Unicode 코드 포인트), 식별자 3~30자 안내를 표시한다. 식별자는 영문으로 시작하고 소문자/숫자/하이픈/언더바를 허용하며 끝 하이픈·예약어를 거부한다. 생성 이후 변경할 수 없다.

사진은 최상단에서 선택·초기화한다. 선택은 object URL 미리보기만 생성하며 저장할 때만 multipart profile JSON + file로 업로드한다. 초기화는 SNS 사진도 제거하는 초안이다. 생성 시 기본 닉네임을 직접 바꿀 수 있고, 로그아웃하면 미완료 상태는 그대로 남아 다음 로그인에 생성 화면으로 진입한다. 생성 완료 시 /blogs/{handle}로 이동한다. 공개 블로그와 글 경로의 underscore 검증도 함께 수정했다.

완료된 프로필은 사진·블로그명·닉네임·읽기 전용 식별자를 표시한다. 변경 사항 저장/취소 버튼을 제공하며 취소는 안전한 내부 returnTo 또는 본인 블로그로 돌아간다. 상단 아바타 메뉴는 진입 페이지 경로·query를 전달한다. 외부 경로·encoded slash/backslash·인증 주소·민감 query·자기 프로필 주소는 반환 경로로 사용하지 않는다. 사진/이름 초안은 저장 전 서버를 바꾸지 않는다. 기존 독립적인 7일 표시 이름 변경 제한을 유지한다.

계정 관리는 생성 폼에서 제거했다. 미완료 계정은 설정 메뉴를 표시하지 않으며 완료 후 설정(/settings/account)에서 탈퇴하기를 제공한다. 7일 유예·같은 네이버 계정 재인증 취소·기한 후 영구 삭제/복구 불가를 안내하고 최종 탈퇴/취소 버튼을 제공한다.

저장 응답 유실·5xx 시 요청을 자동 반복하지 않는다. 입력을 잠그고 서버 상태 다시 불러오기 버튼을 활성화한다. 로그인 복구만으로 편집 초안을 덮어쓰지 않으며 계정 변경 후 이전 응답은 적용하지 않는다.
