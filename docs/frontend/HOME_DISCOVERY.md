# 홈·검색·헤더 개편 (Issue #23)

2026-10-06. 홈은 여러 개발자의 글을 둘러보는 화면이고 개인 블로그와 구분한다.

- 최상단은 돋보기 제출 버튼과 검색어 입력만 제공한다. Enter로도 제출할 수 있다.
- `/search`에서 전체·게시글·프로젝트로 결과를 구분한다. 전체는 종류별 4개 미리보기, 각 종류는 기존 API의 20개 페이지다. 종류를 바꾸면 page=0으로 복귀하고 키워드를 유지한다. 검색 화면에 태그·주제 입력/표시는 없다.
- 홈에는 매일 조약돌을 쌓는 CSS 배너, 공감받은 글 3개와 최신 글을 배치한다. 공감받은 글은 첫 페이지의 최근 공개 글 20개 중 좋아요>0 기준이며 전역 인기 순위가 아니다. 좋아요 동률은 게시 시각·생성 시각·BIGINT ID 내림차순이다. 원본 최신 목록은 변경하지 않는다. 글/좋아요가 없으면 실제 빈 상태를 표시한다.
- 헤더 왼쪽은 홈·게시글·프로젝트, 로그인한 오른쪽은 글 작성·내 블로그·로그아웃·프로필 사진이다. 기존 관리 메뉴를 헤더에서 제거하고 프로필/설정은 사진의 드롭다운에 남긴다. 비로그인은 로그아웃/사진 대신 네이버 로그인이다.
- 공개 `/posts` 목록은 목록 재사용으로 기존 API/페이징을 유지한다. `/?q=...` 키워드 링크는 게시글 검색으로 연결하고 기존 tagId/categoryId 탐색 URL은 유지한다. 분류 탐색 화면은 직접 URL로 계속 접근 가능하다.
- Pretendard v1.3.9 가변 다이나믹 서브셋 92개와 SIL OFL을 `public/fonts/pretendard`에서 직접 제공한다. unicode-range/font-display:swap을 유지하고 한글 본문에 필요한 서브셋만 브라우저가 요청한다. CSS 상대 경로만 자체 자산 경로로 변경했다. 외부 폰트 요청이나 실행 스크립트가 없다. 코드의 monospace 글꼴은 유지한다.

공식 원본: https://github.com/orioncactus/pretendard/tree/v1.3.9

## 검증 기록

Node 22 테스트119개·타입 검사·Next 운영 빌드 성공. 첫 샌드박스 테스트는 HTTP listen 권한 제한으로 실패했으며 같은 테스트를 로컬 허용 환경에서 전부 통과했다. Turbopack이 바깥 node_modules 링크를 거부하여 lockfile 기준으로 작업 폴더에 의존성을 설치하고 빌드를 통과했다. 비밀 설정은 복사하지 않았다.

모의 글·프로젝트를 통한 홈/통합 검색과 한쪽 API 오류/다른 쪽 빈 결과를 브라우저에서 확인했다. 로그인 헤더는 임시 로컬 모의 인증이며 운영 계정 로그인 검증과 다르다. 375px 모바일에서 가로 넘침이 없고 Pretendard font-family 적용을 확인했다. 실제 OAuth/운영 회원 쓰기는 수행하지 않았다. 운영 API·Workers 배포 결과는 최종 PR 기록으로 확인한다.
