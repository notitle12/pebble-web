# 프런트엔드 인계

## 구현 범위

- Next.js 16.3.8, React 19.3.0, TypeScript 7.0.2. 참고 이미지의 흰색·푸른 포인트·접이식 사이드바와 로그인 카드를 구현한다.
- 파란 조약돌은 참고 이미지를 바탕으로 투명 SVG로 구현했다. 외부 폰트·이미지 생성·유료 서비스가 필요하지 않다.
- 공개 Post/Project 목록·검색·페이지·상세, 태그별 Post 탐색, 아카이브·소개와 예시 콘텐츠가 표시된 미리보기 경로를 제공한다.
- Naver authorization/login, 두 callback 경로, Refresh·logout·본인 조회, 최초/변경 프로필 설정을 기존 백엔드 계약에 연결한다.
- 콘텐츠 소유자의 Post 썸네일 PUT/DELETE, Project 미디어 POST/PATCH/DELETE, 좋아요를 상세 화면에 연결한다.
- 토큰은 메모리에만 보관하고 JSON으로만 렌더링한다. 서버 콘텐츠를 HTML로 삽입하지 않는다.

## 후속

실제 Naver 로그인과 프로필 저장, 소유자 미디어 처리·운영 삭제 큐를 브라우저에서 확인해야 한다. callback 등록과 API Origin은 실행 환경에 맞춘다. 콘텐츠 작성/편집·댓글·관리자 화면은 다음 기능이다. 현재 GitHub 원격 프런트엔드 저장소는 생성하지 않았다.
